# Проект: Blogicum (Блоговая платформа)


###  Ключевые возможности:
* **Личные кабинеты:** Просмотр информации о пользователях, пагинация публикаций автора, кастомные страницы редактирования профиля и встроенная смена пароля.
* **Управление контентом:** Публикация постов с привязкой к категориям, локациям и дате, поддержка черновиков.
* **Система комментариев:** Полноценный цикл (создание, обновление, удаление автором) с защитой через метод `dispatch` в CBV.
* **Оптимизация:** Применение `select_related` для исключения проблемы N+1 запросов при рендеринге связанных данных.

###  Стек технологий:
Python 3.12, Django 4.2, SQLite, Pytest (автоматическое тестирование бизнес-логики).

### 💻 Как запустить локально:
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Выполнить миграции и запустить сервер:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
